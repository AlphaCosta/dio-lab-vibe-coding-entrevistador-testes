# 📌 Projeto: Agentes Entrevistadores QA

Este projeto contém **dois agentes especializados** para conduzir entrevistas estruturadas em vagas de Qualidade de Software:

- **Entrevistador QA Manual**: Focado em testes manuais.
- **Entrevistador QA Automação**: Focado em testes automatizados.

Cada agente possui:
- Objetivo claro.
- Regras operacionais.
- Estrutura de entrevista com perguntas organizadas em blocos.
- Abertura sugerida.
- Modelo de diagnóstico final com matriz de avaliação.
- Prompt pronto para uso.
- Perguntas adicionais opcionais.

---

## 📂 Estrutura dos Arquivos
- `entrevistador_QA.txt` → Agente para entrevistas de **Testes Manuais**.
- `entrevistador_QA_Automacao.txt` → Agente para entrevistas de **Testes Automatizados**.
- `README.md` → Este arquivo com instruções gerais.

---

## 🎯 Objetivo Geral
Fornecer **roteiros prontos** para entrevistas técnicas, garantindo:
- Estrutura clara.
- Diagnóstico analítico.
- Avaliação por critérios técnicos e comportamentais.

---

## 🚀 Como Usar
1. Escolha o arquivo do agente conforme a vaga:
   - QA Manual → `entrevistador_QA.txt`
   - QA Automação → `entrevistador_QA_Automacao.txt`

2. Copie o **prompt pronto para colar** do arquivo.

3. Utilize em um modelo de IA ou como guia para entrevistas reais.

4. **Importante:**
   - Faça **uma pergunta por vez**.
   - Aguarde resposta antes de prosseguir.
   - Gere diagnóstico **somente após confirmação explícita**.

---

## 🧾 Diagnóstico Final
Cada agente gera um diagnóstico com:
- Pontos fortes e pontos a melhorar.
- Matriz de avaliação (0–4) por critério.
- Pontuação total e senioridade sugerida.
- Recomendações práticas.

---

## ✅ Benefícios
- Padronização das entrevistas.
- Avaliação técnica e comportamental.
- Redução de vieses.
